# KetchupE 3.0.15

[3.0.14](3.0.14.md)의 일일자금일보 PNG 출력에서 페이지가 나뉘던 문제를 수정했다.

긴 입금·지급 내역은 설명 칸(B:C, F:G)을 병합하고 줄바꿈하며 행 높이를 늘린다. 이때 인쇄 영역이 세로 한 페이지를 넘으면 PNG가 2페이지로 이어 붙여져 하단 합계표와 사업부문 자금현황표(KC)가 페이지 경계에서 갈라졌다. 인쇄 설정을 가로·세로 모두 한 페이지에 맞추도록(`fitToHeight` 0 → 1) 바꿔 항상 한 장의 PNG로 출력한다. 내용이 길수록 전체가 조금 축소된다.

실제 일보 3개 파일에 짧은·긴 내역을 넣어 LibreOffice 경로로 생성했고, 모든 PNG가 1페이지이며 긴 문장이 잘리지 않고 표가 갈라지지 않는 것을 확인했다. 활성화된 Excel 경로의 실제 출력은 아직 검증하지 않았다.
