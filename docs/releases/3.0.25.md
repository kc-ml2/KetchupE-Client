# KetchupE 3.0.25

## PNG 그래프 출력 안정화

- Windows·macOS·Linux 공통으로 숨김 Electron 창 캡처 대신 설치된 sharp로 SVG를 PNG로 직접 변환한다. PNG 생성은 Wayland/X11의 화면 갱신이나 모니터 크기에 의존하지 않는다.
- 출력 너비 1600px, 비례 높이, 흰 배경, 크기 제한, 취소 및 60초 제한을 유지한다. PDF는 기존 격리된 Electron 인쇄 경로를 사용한다.
- 원본 데이터와 분석 결과는 유지된다. 글꼴과 글자 배치는 운영체제에 설치된 글꼴 및 렌더러에 따라 약간 달라질 수 있다.

## 검증

- 실제 TGA 첫 시트 10,869행으로 PNG·HTML·PDF·PPTX 생성까지 macOS에서 약 5초에 완료했다. 한글, 축·단위, W(800)·Tmax 주석을 확인했다.
- 별도 Mac 실행에서 선 그래프 PNG 0.22초, 산점도 1.84초, 전체 값 라벨 스트레스 사례 11.32초였다. 해당 파일과 환경의 측정값이며 일반 성능 보장은 아니다.
- 전체 테스트 647개 통과, 환경 의존 6개 건너뜀. Electron TypeScript 및 프로덕션 빌드 통과. ESLint 오류 0개, 기존 Navigation Hook 경고 1개.
- CI는 디스플레이 환경 변수를 비운 상태에서 실제 PNG 변환·색상·크기·취소·시간 제한을 검사하고, Linux·Windows·macOS에서 대용량 PNG/PDF 출력과 정확한 이미지 크기를 확인한다. 개인 TGA 파일은 저장소와 CI에 포함하지 않는다.
- Ubuntu 26.04 Wayland 실기기의 전체 대화 흐름은 직접 검증하지 않았다. PNG 변환에서 숨김 창 의존성을 제거한 수정이다.
