# KetchupE 3.0.12

일일자금일보의 병합 셀 테두리, 사라진 이월 검증 수식, 집행내역 잘림을 개선했다. 최종 출력은 사용자 PC의 Microsoft Excel로 재계산한 XLSX를 기준으로 만들며, Excel 출력이 불가능하면 설치된 LibreOffice로 자동 전환한다.

## 서식과 수식 보존

- 원본의 모든 셀에서 글꼴·테두리·정렬·표시 형식·채우기를 복사한다. 병합 범위에 포함된 빈 셀의 개별 서식과 기존 행 높이도 유지한다.
- 기존 수식을 일괄 삭제하거나 하단 검사 셀을 비우던 처리를 제거했다. 갱신 대상으로 지정한 입력과 계산식만 변경한다.
- 이월 비교 수식은 특정 주소를 기준으로 복구하지 않는다. 기초금액과 과거 날짜 시트의 참조를 분석하고, 해당 시트의 기초·마감 영역을 확인한 뒤 이전 일보의 마감금액으로 연결한다.
- 모호한 참조, 없는 날짜 시트, 외부 통합문서 참조는 검증 오류로 중단한다. 이미 삭제된 수식은 정상 원본 양식이 필요하다.
- 새 시트를 추가할 때 기존 과거 시트의 XML은 보존한다.

## 실제 재계산과 PNG 출력

- Windows에서는 Excel COM, macOS에서는 AppleScript로 임시 XLSX를 재계산·저장한다.
- 계산된 수식 결과와 계좌잔고·총 원화·집행 마감잔액을 검증한다. 검증된 계산값만 원본 서식이 보존된 최종 XLSX에 반영한다.
- 그 최종 XLSX를 다시 열어 PDF로 출력하고 PDFium으로 PNG를 만든다. PDF 출력 과정에서 제공할 XLSX 바이트가 바뀌지 않았는지도 확인한다.
- 사업부 보조표까지 인쇄 범위에 포함하고, 여러 PDF 페이지는 세로로 연결한다. PNG를 만들 때 주석 아이콘은 표시하지 않으며 XLSX의 주석은 유지한다.

## Excel 실패 시 LibreOffice 전환

- Excel 미설치, 보기 전용·인증 문제, 자동화 또는 출력 실패 시 처음 준비한 XLSX부터 LibreOffice로 다시 계산·검증·출력한다.
- 금액·수식 검증 실패와 사용자 취소는 자동 전환 대상에서 제외한다. 결과 메시지와 감사 기록에 실제 출력 엔진과 전환 사유를 남긴다.
- LibreOffice는 별도 설치가 필요하다. 기본 설치 경로와 PATH에서 찾으며, 필요한 경우 `KETCHUPE_LIBREOFFICE_PATH`로 실행 파일을 지정할 수 있다.
- LibreOffice 인쇄용 메모리에서는 최종 파일의 수식 저장값을 고정해 변동 수식의 값 차이를 막는다. 이 인쇄용 상태는 파일에 저장하지 않는다.
- 일보 작업 제한 시간을 8분으로 늘리고, 취소 시 임시 파일과 네이티브 프로세스를 정리하도록 연결했다. macOS에서는 Excel 작업이 겹치지 않게 한다.

## 집행내역 잘림 보정

- 새 집행내역의 설명 영역은 금액 칸 직전까지로 계산한다. 특정 제목이나 셀 주소, 글자 수 기준을 사용하지 않는다.
- 출력 엔진이 실제 글꼴로 측정해 표시 영역을 넘는 항목만 줄바꿈한다. 필요하면 비어 있는 옆 설명 셀까지 병합하고, 측정된 높이만큼 행을 늘린다.
- 짧은 항목과 기존 줄바꿈 설정은 기본적으로 유지하며 글꼴 크기는 줄이지 않는다. 보정한 배치는 최종 XLSX와 PNG에 함께 반영한다.
- 옆 셀에 값이 있거나 다른 병합 범위와 충돌하거나 Excel 최대 행 높이를 초과하면 오류로 알려준다.

## 빌드와 검증

- 앱 버전과 잠금 파일을 `3.0.12`로 올렸다. PDFium을 직접 의존성으로 지정하고 패키징 설정을 추가했다.
- macOS Excel 자동화 권한 설명과 엔타이틀먼트를 추가했다.
- 릴리스 구성에서 Electron 테스트 385개, Electron TypeScript 검사, 프로덕션 빌드를 통과했다. LibreOffice 설치가 필요한 통합 테스트 2개는 이 릴리스 검사에서 건너뛰었다.
- 앞선 macOS LibreOffice 25.8.7 실제 출력 검증에서는 긴 집행내역 5개가 두 줄로 표시되고, 해당 행만 20.85pt로 늘어나는 것을 확인했다. 검증에는 별도로 확인한 참조 보정이 포함된 비교용 통합문서를 사용했다.
- 활성화된 macOS Excel의 성공 출력, Windows의 실제 COM·LibreOffice 실행, 서명된 설치 앱의 자동화 권한 동작은 추가 실기기 검증이 필요하다. 설치 글꼴에 따라 출력 모양이 달라질 수 있다.
