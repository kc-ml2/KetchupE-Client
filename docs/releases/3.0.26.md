# KetchupE 3.0.26

## 일일자금일보(daily_cash) 수정

- 사업부문 자금현황표(KC) `P`열에 KC 계좌잔고를 소수 둘째 자리까지 그대로 기록한다. 화면 표시는 기존처럼 정수이며, 합계 수식이 원본 일보와 같은 값을 계산한다. 총 원화 대사 기준도 해당 소수 차이를 반영한다.
- 주요 집행 내역에서 거래가 없는 행은 `0` 대신 공란으로 둔다. 입금·지급 합계와 마감잔액 계산은 동일하다.
- 정기예금 빈 슬롯에 신규 예금을 기입할 때 같은 구역의 기존 예금 행 서식을 복사해 다른 행과 같은 우측 정렬·표시 형식을 갖게 한다.

## 검증

- `electron/business` 테스트 149개 통과(환경 의존 6개 건너뜀). Electron TypeScript 통과. ESLint 오류 0개, 기존 Navigation Hook 경고 1개.
- 실제 업무 원본 파일로는 검증하지 않았다. 정기예금 정렬 문제는 신규 예금 행의 양식 서식 차이로 판단해 수정했다.
