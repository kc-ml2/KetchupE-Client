# KetchupE 3.0.27

## 일일자금일보(daily_cash) 정기예금 정렬 수정

- 3.0.26의 정기예금 정렬 수정은 원인을 잘못 짚었다. 실제 원인은 원본 일보의 정기예금 한 행에 다른 행에는 있는 증가 칸 `E:F` 병합이 빠져 있어, 값이 좁은 E열 안에서 정렬되어 가운데쯤에 보인 것이다.
- 원화·외화 정기예금과 신탁 구역마다 과반의 행이 쓰는 한 행 병합을, 병합이 빠지고 셀이 비어 있는 행에 보완한다. 3.0.26의 신규 예금 행 서식 복사는 제거했다.

## 검증

- 실제 업무 원본 파일로 다음 영업일 일보를 Excel 엔진으로 생성해 총 원화 대사 일치, 사업부문 P열 소수 유지(표시는 정수), 주요 집행 내역 빈 행 공란, 정기예금 행 정렬을 PNG로 확인했다. 원본 파일과 수치는 저장소에 포함하지 않는다.
- `electron/business` 테스트 150개 통과(환경 의존 6개 건너뜀). Electron TypeScript·프로덕션 빌드 통과.
