# KetchupE 3.0.28

## 일일자금일보(daily_cash) 대화형 진행

- 입력 대기 중 채팅으로 질문하거나 답·수정을 보낼 수 있다. model은 메시지 한 건을 답변/입력 변경/재시도/중단 중 하나로 해석하고, 금액 계산·업무 규칙·검증은 기존 코드가 그대로 한다. 최종 승인은 카드 버튼으로만 한다.
- 멈춘 지점마다 고정 ID(code)와 단계(step), 단계별 소요 시간을 남기고, 실패는 복구 방법(입력 수정/재시도/환경/새 작업)과 함께 원인·입력을 보존한다.
- 시작하면 연결된 폴더에서 파일 이름으로 원천 자료를 찾아 카드에 채운다. 후보가 여럿이면 model이 이름만 보고 고르거나 고르지 않는다. 카드에서 폴더 연결과 다시 찾기를 할 수 있다. `uploadOnly`는 해제했다.
- 첫 실행에서 자료가 거절되면 새 작업 없이 카드를 다시 연다.
- 같은 대화에서 완료한 결과에 대한 질문은 입력 카드를 열지 않고 완료 기록에서 답한다.
- 입력 카드를 줄였다: 파일 항목은 라벨 한 줄과 칩 한 줄, 상태는 라벨 옆 한 단어, 후보는 점선 칩.

## 검증

- 전체 테스트 701개 통과(환경 의존 6개 건너뜀). TypeScript·lint 통과.
- 실제 model(loki)로 대화 32개, 자료 탐색 3개, 완료 결과 질문 6개 발화를 확인했다. 합성 데이터와 직접 쓴 발화 기준이며 실제 업무 파일·설치된 Excel 출력·앱 화면은 확인하지 않았다.
- 주간계획·일보 파일 이름 규칙은 추정 키워드다.
