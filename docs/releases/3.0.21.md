# KetchupE 3.0.21

엑셀 작업의 차트를 직접 작성한 SVG 코드 대신 Apache ECharts 6.1.0의 서버 측 SVG 렌더링으로 그린다. 결과는 여전히 스크립트가 없는 정적 SVG이므로 보고서 CSP, PDF 인쇄, PNG·PPTX 캡처 경로는 그대로다.

## 차트 종류와 옵션

- 기존 막대·선·산점도·원형에 영역, 히스토그램, 박스플롯, 히트맵을 추가했다.
- 선·영역·막대·산점도에서 복수 시리즈와 보조 Y축을 지원한다(최대 4개 시리즈).
- `stack`(막대·영역 누적), `horizontal`(가로 막대), `smooth`(곡선), `donut`(도넛), `bins`(히스토그램 구간 수), `value`(히트맵 값 열) 옵션을 추가했다.
- 히스토그램 구간, 박스플롯 사분위수·이상치, 산점도 회귀선은 렌더러가 계산한다. 모델은 원자료 열만 지정한다.
- 기본 그래프 계획(`kind:"chart"`)에 `chartType`(line/area/scatter), `smooth`, `stack`을 추가했다.

## 표시 수정

- 축: 기존 최소·최대·눈금 간격·눈금 목록·소수 자릿수·라벨에 로그 스케일(`scale:"log"`)을 추가했다. 0 이하 값이 있으면 그리지 않고 이유를 안내한다.
- 주석: 최대점에 더해 최소점과 평균선을 지원한다. 값과 위치는 코드가 계산한다.
- 값 라벨 표시(`labels`, 500점 이하)와 시리즈 색상(`colors`)을 지정할 수 있다.
- 보조선: `referenceLines`로 지정한 X 또는 Y 값에 점선을 긋는다. 최대점·최소점 주석은 그 위치에 세로 점선을 함께 그린다.
- 특정 X의 값 표시: 주석 `kind:"valueAt"`과 `x`로 가장 가까운 측정점의 값을 표시한다(예: 800℃의 Residue). 보간하지 않는다.
- 그리드 선: `grid`로 점선·실선·숨김을 고른다.
- 축 수정은 원형·히트맵을 제외한 차트에서, 주석은 선·영역·산점도·막대에서 지원한다. 범주형 X축은 라벨만 바꿀 수 있다.

## 수정 대화

- 수정 단계에서 결과를 바꾸는 요청이 아닌 질문("지금까지 수정 요청을 모아줘", "지금 축 범위가 뭐야")은 대화로 답하고 결과 파일을 다시 만들지 않는다. 반영한 수정 요청 원문을 최근 20개까지 작업 상태에 보관한다.
- 추가 질문에 답하는 동안에는 입력 카드에 글 상자를 하나만 보여 준다. 카드의 글 상자와 메시지 입력창이 같은 곳으로 전달된다는 안내를 카드와 입력창에 표시한다.

## XLSX

XLSX는 Excel 네이티브 차트만 저장한다. 단일 시리즈 막대(가로 포함)·선·영역·산점도·원형(도넛 포함)을 지원하고, 복수 시리즈·보조축·숫자형 X축 선 그래프·전체 데이터 차트·히스토그램·박스플롯·히트맵과 표시 수정은 HTML/PDF/PNG/PPTX로 안내한다.

## 유지되는 동작

- 선 그래프는 측정 순서를 유지하고 원본 행이 빠진 곳에서 선을 끊는다. 점을 솎아내지 않는다.
- 표시 범위 밖 점의 수, 동률 최대점, 주석 좌표는 차트 아래 주석 문구로 남긴다.
- 같은 보고서를 다시 그리면 같은 SVG가 나온다. 한 보고서 안의 여러 차트는 id와 스타일 클래스가 겹치지 않는다.
