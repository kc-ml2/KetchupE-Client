# KetchupE 3.0.13

[3.0.12의 일일자금일보 출력 개선](3.0.12.md)을 포함하며 Windows CI에서 발견된 테스트 파일명 문제를 수정했다.

LibreOffice 테스트가 실제 파일명에 큰따옴표를 넣어 Windows에서 파일 생성부터 실패했다. 모든 대상 OS에서 허용되는 작은따옴표로 바꾸고 한글·공백·달러 기호와 따옴표가 있는 시트명 검증은 유지했다. 앱의 계산·출력 동작은 그대로다.

기존 커밋과 `v3.0.12` 태그는 유지한다. 앱 버전과 잠금 파일을 `3.0.13`으로 갱신해 수정된 테스트를 포함한 새 빌드를 실행한다. 해당 LibreOffice 테스트 5개는 로컬에서 통과했다.

macOS 서명 빌드는 GitHub Actions의 `BUILD_CERTIFICATE_BASE64`, `P12_PASSWORD`, `KEYCHAIN_PASSWORD` 설정이 비어 있어 중단된 상태다. 서명 및 공증에 필요한 저장소 설정을 복구해야 macOS 설치 파일을 생성할 수 있다.
