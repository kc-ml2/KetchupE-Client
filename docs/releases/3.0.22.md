# KetchupE 3.0.22

## 업무 결과 사이드 패널

- 업무 결과를 채팅 열에서 빼서 계약서 초안 캔버스처럼 오른쪽 사이드 패널에 표시한다. 닫기 버튼으로 닫을 수 있고, 닫으면 입력창 위에 "업무 결과 다시 열기" 버튼이 나온다. 스레드를 바꾸거나 실행이 시작되면 패널이 다시 열린다.
- 차트 미리보기를 누르면 확대 보기가 열린다. 50~400%로 확대·축소하고 ESC나 배경 클릭으로 닫는다.
- "이 결과 수정하기", "이전 버전에서 수정" 버튼을 없앴다. 수정은 채팅으로 요청하며, 결과 버전 선택에서 이전 수정본을 고르면 그 버전을 기준으로 수정한다.

## 빌드

- macOS 개발자 서명이 준비될 때까지 `v*` 태그 푸시의 macOS 자동 빌드를 꺼 두었다. 수동 실행은 그대로다.

## 검증

- `tsc -b`, `tsc -p tsconfig.electron.json`, `eslint .` 통과.
- `vitest run` 전체: 테스트 560개 통과, 5개 건너뜀.
- 설치된 앱에서의 화면은 확인하지 못했다.
