# KetchupE 3.0.24

## 대용량 그래프 출력

- PNG·PDF 렌더링에 HTML 전체를 넣은 `data:` URL 대신 작업별 임시 HTML 파일을 사용한다. 산점도나 전체 값 라벨 때문에 SVG가 커져도 Chromium의 URL 길이 제한으로 `ERR_INVALID_URL (-300)`이 발생하지 않는다.
- 원본 데이터와 차트 표시 설정은 그대로 유지한다. 시간 제한이나 샘플링 기본값은 변경하지 않는다.
- 임시 파일은 전용 폴더에 제한된 권한으로 만들고 성공·실패·취소 후 삭제한다. 렌더러의 sandbox, 스크립트 차단, 외부·다른 로컬 파일 접근 차단을 유지한다.
- PNG는 화면 밖 렌더링을 사용해 데스크톱 해상도가 작아도 요청한 1600px 너비를 유지한다. Windows CI에서 일반 숨김 창이 1008px로 제한되는 문제를 확인해 보완했다.

## 검증

- 실제 TGA 첫 시트 10,869행의 선·산점도·전체 값 라벨 그래프를 Electron 39에서 확인했다. 기존 산점도 `data:` URL(7,527,778자)은 `ERR_INVALID_URL`로 실패하고, 수정 후 같은 SVG의 PNG·PDF가 생성된다.
- Mac 단일 실행에서 산점도 PNG 0.680초 / PDF 1.027초, 전체 값 라벨 PNG 1.211초 / PDF 2.915초였다. PDF를 다시 읽고 PNG의 두 계열 색상 픽셀을 검사했다. 이는 해당 파일·환경의 측정값이며 일반 성능 보장은 아니다.
- 자동 테스트는 큰 HTML 원문 보존, 요청 차단, 임시 파일 권한·정리, 취소·로드 실패, 동시 출력 격리를 검사한다.
- 전체 테스트 644개 통과 / 환경 의존 6개 건너뜀. Electron TypeScript와 프로덕션 빌드 통과. ESLint 오류 0개이며 기존 Navigation Hook 경고 1개는 유지한다.
- `Excel render regression` CI는 공개 합성 데이터로 실제 Electron의 기존 실패와 수정 후 PNG·PDF 출력을 Linux(Xvfb/X11), macOS, Windows에서 검사한다. 개인 TGA 파일은 저장소나 CI에 포함하지 않는다.
- Ubuntu 26.04의 실제 Wayland 데스크톱과 설치된 앱의 전체 대화 흐름은 별도 검증 대상이다.
