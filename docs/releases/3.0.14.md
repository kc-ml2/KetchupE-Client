# KetchupE 3.0.14

[3.0.13](3.0.13.md)의 일일자금일보 출력에 템플릿 수식 보존과 코드 정리를 더했다.

- 전일금액 셀(D9~D26 등)의 `='전일시트'!H{행}` 수식을 숫자로 바꾸지 않고, 새 시트의 직전 시트를 참조하도록 다시 연결한다. 전일 H 캐시값이 이월 금액과 같을 때만 수식으로 두며 수동 보정값은 기존처럼 숫자로 기록한다.
- 주요 집행내역 금일 기초금액(H{기초})의 템플릿 수식 `=D{마감}`을 유지한다.
- 이월 검증식(D236 등)은 3.0.12와 같이 직전 시트의 마감잔액을 참조하도록 다시 만든다.
- 사용하지 않는 반환값과 중복 판정을 제거하고, 출력 엔진 타임아웃과 PDF·이미지 한도를 이름 있는 상수로 정리했다. `npm run lint` 오류를 모두 수정했다.

실제 일보 3개 파일에서 수식 보존을 확인했다. Excel·LibreOffice 재계산과 PNG 출력은 엔진이 있는 환경에서 확인해야 한다.
